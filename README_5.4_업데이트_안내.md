- 기존 5.3 상담 엔진을 **변경하지 않고** 규칙 개선안을 별도의 비교 화면에서 평가합니다.
- 부정·정정·인용된 표현을 위험으로 잘못 분류하는 문제를 줄이고, 여러 형태의 위험 확약·설명 생략 표현을 추가 탐지합니다.
- 연구용 프로토타입입니다. 실제 투자상품 설명의 적법성 판단 또는 자동 가입 차단의 검증된 개선이라고 주장하지 않습니다.

## 로컬 Node.js 재현 결과

| 자료 | 기존 정확도 | 후보 정확도 | 기존 F1 | 후보 F1 | 기존 FP/FN | 후보 FP/FN |
| --- | ---: | ---: | ---: | ---: | --- | --- |
| 기존 100건(개발용) | 70.0% | 100.0% | 71.70% | 100.00% | 18 / 12 | 0 / 0 |
| 별도 작성 40건(추가 검증) | 57.5% | 67.5% | 51.43% | 68.29% | 6 / 11 | 7 / 6 |

주의:
- 100건은 이전 오류를 분석·규칙을 조정할 때 참고했으므로 **학습/개발용 성능**입니다. 100%를 제품의 정확도로 발표하면 안 됩니다.
- 40건은 개발 100건과 **문장 중복 없이 별도 작성하여 고정한 합성 시험**이며, 후보 규칙을 40건 결과에 맞춰 다시 조정하지 않았습니다. 별도 작성이라고 해서 외부 독립 검증이나 통계적으로 대표성 있는 검증을 뜻하지는 않습니다.
- 40건 기준 재현율은 45%→70% 개선됐지만 **오탐은 6→7건으로 증가**했습니다. 두 변화 모두 공개해야 합니다.
- 손실 없는 자동가입 차단 시스템이라고 주장할 수 없습니다. 현재 개선 분류기는 실시간 상담 화면에서 동작하지 않습니다.
- 실제 금융소비자 데이터·녹음·신분정보는 평가 화면에 넣지 마세요.

## 발표용 표현 예시

> 규칙 기반 위험 표현 탐지 엔진의 오류를 분석한 뒤, 부정·인용·정정 문맥 처리와 위험 표현 패턴을 추가했습니다. 개발에 사용한 100개 합성 문장과 구분하여 새로 작성한 40개 합성 문장으로 비교한 결과, 정확도가 57.5%에서 67.5%로 상승했습니다. 다만 오탐은 6건에서 7건으로 증가했고, 전문가가 독립 주석한 실제 금융 상담에 대한 성능 검증은 별도로 필요합니다.
